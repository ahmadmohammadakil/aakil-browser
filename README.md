# AAKIL — متصفحك الخاص

AAKIL هو متصفح شخصي بواجهة عربية داكنة، مبني ليبدأ على Windows 10/11 مع مسار Android قابل للبناء من قاعدة كود مشتركة. الإصدار الحالي هو **0.1.0** ويقدم تجربة المتصفح والخصوصية المحلية، بينما تبقى وحدة VPN اختيارية وغير مرتبطة بمزوّد محدد.

## ما يعمل في الإصدار الحالي

تتضمن الواجهة صفحة بداية، تبويبات، شريط عنوان وبحث، اختصارات سريعة، الوضع الخاص، سجلًا محليًا قابلًا للمسح، مؤشرات حماية محلية، إعدادات، وفتحًا خارجيًا للرابط. يمكن للمستخدم فتح مواقع HTTPS داخل مساحة المعاينة، مع زر فتح خارجي للمواقع التي تمنع العرض داخل iframe.

يُحفظ السجل محليًا فقط داخل تخزين التطبيق. عند تفعيل الوضع الخاص لا تُضاف الزيارات الجديدة إلى السجل. لا يتضمن الإصدار الحالي مدير كلمات مرور أو مزامنة سحابية أو إرسالًا مركزيًا لسجل التصفح.

## حالة VPN

زر VPN الموجود في الواجهة هو **واجهة مستقبلية صادقة** وليس نفقًا مزيفًا. يظهر أن الخدمة غير مفعلة لأن المشروع لا يملك خادم VPN أو ملف WireGuard صالحًا. عند إضافة الوحدة لاحقًا، يكون المسار المقترح استيراد ملف WireGuard يملكه المستخدم أو إضافة مزود رسمي مصرح به، مع عدم تضمين حساب مجاني لمزود آخر أو مشاركة حساباته.

لا تستخدم ملف إعداد VPN إلا إذا كان مصدره موثوقًا، ولا تشارك المفتاح الخاص. وجود زر اتصال أو مكتبة WireGuard لا يعني وجود خادم VPN؛ يلزم خادم، مفاتيح، ونقطة اتصال قابلة للوصول.

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

## فحص وبناء الواجهة

```bash
pnpm run build
```

## تشغيل تطبيق Tauri على Linux للتجربة

```bash
pnpm tauri dev
```

## البناء السحابي التلقائي لويندوز

يحتوي المشروع على سير عمل GitHub Actions في `.github/workflows/windows-build.yml`. عند رفع تغيير إلى فرع `main` أو تشغيله يدويًا من تبويب **Actions**، يبني GitHub نسخة Windows x64 على خادم Windows ويضع مُثبّت EXE كملف قابل للتنزيل داخل **Artifacts**. لا يحتاج جهازك إلى Rust أو Visual C++ لهذا المسار؛ هذه الأدوات موجودة على خادم البناء.

بعد نجاح التشغيل، افتح تبويب **Actions** في مستودع AAKIL، اختر عملية **Build AAKIL for Windows**، افتح آخر تشغيل ناجح، ثم نزّل `AAKIL-Windows-x64-EXE`. احتفظ بالمستودع خاصًا ولا تضع أي مفاتيح أو ملفات VPN خاصة داخل GitHub.

## بناء نسخة سطح المكتب

بناء Windows النهائي يجب أن يتم على جهاز Windows مع Visual C++ Build Tools وWebView2 Runtime. بعد فتح المشروع على Windows:

```powershell
pnpm install
pnpm tauri build
```

سيولد Tauri مثبت Windows مناسبًا للإصدار المهيأ. لا أرفق ادعاءً بوجود ملف EXE نهائي قبل اختباره على Windows نفسه.

## بناء Android

يلزم Android Studio وAndroid SDK وNDK وJDK 21، ثم تهيئة الهدف مرة واحدة:

```bash
pnpm tauri android init
pnpm tauri android build --apk --target aarch64
```

وللنشر في Google Play استخدم App Bundle موقّعًا:

```bash
pnpm tauri android build --aab
```

يجب توقيع حزمة الإصدار بمفتاحك الخاص وعدم وضع مفتاح التوقيع داخل المستودع.

## البنية

| الجزء | التقنية |
|---|---|
| الواجهة | React 19 + TypeScript + Vite |
| الغلاف الأصلي | Tauri 2 + Rust |
| Windows | WebView2/Chromium |
| Android | Android WebView/Chromium |
| التخزين الحالي | localStorage محلي |
| VPN | واجهة اختيارية غير مفعلة في 0.1.0 |

## التحقق المنفذ

نجح فحص TypeScript وبناء Vite عبر `pnpm run build`. كما نجح تجميع تطبيق Tauri على Linux وإخراج حزمة Debian في `src-tauri/target/release/bundle/deb/AAKIL_0.1.0_amd64.deb`. لم يُختبر التطبيق على Windows الفعلي، ولم تُخرج حزمة Android نهائية داخل البيئة الحالية؛ مشروع Android تم توليده، لكن Gradle توقف أثناء خطوة Rust/الاتصال الداخلي الخاصة بـ Tauri، لذلك ينبغي تنفيذ البناء على جهاز تطوير Android مستقر قبل اعتماد APK.

## ملاحظات قبل الاعتماد الشخصي

هذه النسخة هي أساس قابل للبناء والتطوير وليست بديلًا عن مراجعة أمنية مستقلة. لا تعتمد على المتصفح لحماية حسابات حساسة قبل اختبار إدارة الجلسات والنوافذ المنبثقة والتنزيلات وسياسات الشهادات. عند إضافة VPN يجب اختبار تسرب DNS وIPv6 وانقطاع النفق وKill Switch على كل نظام.
